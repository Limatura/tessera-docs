暗号化した共有は、送り手のマシンで封をしてから送られます。インスタンスは鍵を持たないままバイト列を保存し、配るだけです。開くのは受け取る側のマシンです。

デフォルトはオフです。受け付けるには `features.encryption` を有効にします。あとでオフにすると新しいものは断られ、既存のものは引き続き受け取れます。

## 誰から守るか

**運営者と、運営者の持っているものを手に入れた人。** データベースのダンプ、バケットのコピー、顧客のオブジェクトを読むストレージ事業者。どれに見えるのも封をしたバイト列だけです。

なので、運営者が知らない人のために動かすインスタンスでは持っておく価値があります。自分のためだけに動かすインスタンスでは、締め出す相手は自分だけです。

<Callout type="warn" title="嘘をつくページからは守れない">
ブラウザで封をするコードは、同じサーバーが送ってきた JavaScript です。鍵が欲しい運営者は、鍵を送り返すページを配ることができます。これはどんな Web アプリも内側からは防げません。防げるのは、保存したデータを後から読まれることです。コマンドラインにはこの穴はありません。そのコードは、通信先のサーバーから来たものではないからです。
</Callout>

## 鍵の持ち方は二通り

**リンクに入れる。** 鍵は共有のアドレスの `#` の後ろに書かれます。ブラウザはこの部分をサーバーに送りません。リンク全体を持っている人は開けますが、受け取りコードだけでは開けません。

**パスワードから作る。** 鍵をパスワードから導くので、コードとパスワードがあれば足り、どちらも電話で読み上げられます。

<Callout type="error" title="パスワードから作る鍵には代償が二つある">
保存されたバイト列を持っている人は、オフラインでパスワードを推測できます。そのためパスワードは 12 文字以上が必要で、それより短いとクライアントがアップロード前に断ります。また鍵がパスワードから来ているので、こうした共有のパスワードは変更も削除もできません。
</Callout>

## 隠れるもの、隠れないもの

| 隠れる | 隠れない |
|---|---|
| 中身 | 各ファイルの大きさ |
| ファイル名と種類 | ファイルの数 |
| タイトル | 作った日時と期限 |
| テキスト共有の言語 | 取得された回数と、取得元 |

右の列は、インスタンスが容量制限、期限、回数制限を守るために必要な情報です。

## 動きが変わるところ

- **複数のファイルは一つずつ届きます。** アーカイブにはなりません。アーカイブはサーバーが読めない中身からは作れません。
- **リンクプレビュー**には、エンドツーエンド暗号化されていることとサイズだけが出ます。
- **ウイルススキャンの対象外です。** スキャナーが読めるものがありません。[ウイルススキャン](/ja/docs/scanning)を見てください。
- **テキストを生のリンクからプレーンテキストとして開けません。** 先にクライアントで復号する必要があります。

## コマンドラインから

`tessera` コマンドで、暗号化の有無に関係なく共有を送ったり取ってきたりできます。リポジトリの `apps/cli` からビルドします。パッケージ化したリリースはまだありません。

```bash
tessera send --server https://files.example.com --encrypt holiday/*.jpg
tessera send --server https://files.example.com --encrypt --password report.pdf
echo "a note" | tessera send --server https://files.example.com -
tessera get 'https://files.example.com/s/0ZPQ4M7K#…' -o downloads/
```

`--password` はパスワードをその場で尋ねるか、`TESSERA_PASSWORD` から読みます。コマンドラインには書きません。書くと `ps` に見えてしまいます。`--encrypt` なしだと、通常の共有パスワードになります。`--server` と `--token` は `TESSERA_SERVER` と `TESSERA_TOKEN` からも読めます。トークンがなければ匿名でアップロードします。`--expires` は時間、`--max-uses` は回数です。

アップロードは接続が切れても再開します。`get` は名前の中の普通のパス部分だけを残すので、指定したディレクトリの外には書き込みません。既にあるファイルも上書きしません。
