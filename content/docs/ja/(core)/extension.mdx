拡張機能は、右クリックしたものをインスタンスにアップロードしてリンクをコピーします。Chrome、Edge、Brave などの Chromium 系ブラウザと、Firefox 128 以降で動きます。

## インストール

ブラウザのストアにはありません。[リリースページ](https://github.com/Limatura/tessera/releases)からダウンロードして展開してください。Chromium 系ブラウザには `tessera-extension-chrome.zip`、Firefox には `tessera-extension-firefox.zip` を使います。

- **Chromium 系ブラウザ**:`chrome://extensions` を開いてデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選びます。
- **Firefox**:`about:debugging#/runtime/this-firefox` を開き、「一時的なアドオンを読み込む」で展開したフォルダの `manifest.json` を選びます。このビルドは Mozilla の署名を受けていないので、Firefox を再起動すると外れます。

更新するときは、新しい版を元のフォルダに上書きで展開し、同じページで拡張機能を再読み込みします。

## インスタンスにつなぐ

拡張機能の設定を開いてインスタンスのアドレスを入力し、「保存して接続」を押します。ブラウザが、拡張機能がそのアドレスにつないでよいかを尋ねます。ほかのサイトへの許可は求めません。LAN や Tailscale 上のインスタンス向けに、素の `http` でも使えます。

サインインしなくても使えます。アカウントがなければ、インスタンスが許している限り匿名でアップロードします。

「ログイン」はインスタンス自身のサインインページを新しいタブで開くので、パスワード、認証アプリのコード、パスキー、外部プロバイダーのどれでも使えます。サインインが済むと、拡張機能はそこで API トークンを作り、タブを閉じます。トークンの名前は「ブラウザ拡張機能」にブラウザと日付を付けたものです。共有の作成、一覧、削除ができ、アカウント自身ができること以上はできません。この方法には、アカウントに API トークンを管理する権限が要ります。なければ管理者に頼むか、トークンを貼り付ける方法を使ってください。

「API キーを使う」は、サイトで作ったトークンを貼り付ける方法です。拡張機能は保存する前に、インスタンスに有効か確かめます。

ログアウトすると、ブラウザがまだサイトにサインインしていれば、拡張機能は自分で作ったトークンを取り消します。そうでなければトークンは有効なままで、拡張機能がサイトの「API キー」ページで取り消すよう伝えます。貼り付けたトークンは、自動では取り消されません。

## 右クリックメニュー

右クリックして「Tessera にアップロード」を選びます。何が出るかは、どこを右クリックしたかによります。

| 右クリックしたもの | 選べること |
| --- | --- |
| 画像、動画、音声 | そのファイルをアップロードする |
| リンク | リンク先のファイルをアップロードする、またはリンクそのものを共有する |
| 選択したテキスト | ノートとしてアップロードする |
| ページ | ページの URL を共有する |

リンクや URL を共有すると[リンク共有](/ja/docs/shares#送る)になり、開いた人はそのアドレスに送られます。

アップロードが終わると、リンクがクリップボードに入り、通知が出ます。通知をクリックすると共有が開きます。

選択したコードは言語を保つので、共有ページで色付けされます。拡張機能は言語をまずコードブロックから、次にページのアドレスにあるファイル名から読み、最後にだけ推測します。ふつうの文章をコードと取り違えることはありません。

### ファイルが取れないとき

拡張機能はまず自分でファイルを取りに行きます。cookie も送るので、サインインしないと見えない画像も取れます。ファイルのあるサーバーが断ったときは、それを表示しているページが代わりに取ります。上限は 64 MiB です。そういうサイトでそれより大きいファイルには、設定の「任意のサイトからメディアを取得」が要ります。これはすべてのサイトへのアクセスをブラウザに求めます。

ストリーミングの動画には丸ごとのファイルがないので、アップロードできません。

## アップロードの既定値

右クリックでのアップロードと、ポップアップで入力したノートは、設定の次の項目に従います。

- **エンドツーエンド暗号化**:最初はオフで、インスタンスが提供しているときだけ表示されます。ファイルはブラウザの中で封をされ、鍵はリンクの `#` の後ろに入ります。[エンドツーエンド暗号化](/ja/docs/encryption)を参照してください。リンク共有は暗号化しません。サーバーがアドレスを読めないと、人を送れないからです。
- **保存期間**:共有がどれだけもつか。選ばなければインスタンスの既定値で、インスタンスの上限を超えることはありません。
- **読んだら削除**:最初はオフ。共有は最初に受け取られた時点で使えなくなります。
- アップロードが終わったときのリンクのコピーと、終わったときや失敗したときの通知。どちらも最初はオンです。

インスタンスがどれかを受け付けなかったときは、共有を削除します。頼んだのと違う設定の共有は残しません。サイトでのアップロードはサイト自身の選択に従い、この設定は使いません。

## ポップアップ

拡張機能のアイコンをクリックすると、アップロード中のもの(取り消せます)と自分の共有(削除できます)が見られます。短いノートをその場でアップロードする欄もあります。「ファイルをアップロード」はサイトのアップロードページを開きます。ディスクからファイルを選ぶのはそちらです。サイトを開くボタンと、アカウントが使えるなら管理画面を開くボタンもあります。

<Callout type="warn" title="暗号化した共有のリンクは、アップロードしたブラウザしか出せない">
  鍵がインスタンスに届くことはありません。別のブラウザでも共有は一覧に出ますが、完全なリンクは作れません。
</Callout>
