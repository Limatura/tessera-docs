description: 用右鍵選單上傳圖片、連結或選取的文字

擴充功能會把你按右鍵的東西上傳到你的機器,並複製連結。它可以在 Chrome、Edge、Brave 等 Chromium 瀏覽器上用,Firefox 要 128 以上。

## 安裝

它沒有上架瀏覽器的商店。請到[發布頁](https://github.com/Limatura/tessera/releases)下載並解壓縮:Chromium 瀏覽器用 `tessera-extension-chrome.zip`,Firefox 用 `tessera-extension-firefox.zip`。

- **Chromium 瀏覽器**:打開 `chrome://extensions`,開啟開發人員模式,選「載入未封裝項目」,再選解壓縮出來的資料夾。
- **Firefox**:打開 `about:debugging#/runtime/this-firefox`,選「載入暫用附加元件」,再選解壓縮資料夾裡的 `manifest.json`。這個版本沒有經過 Mozilla 簽署,所以 Firefox 重新啟動後就會移除它。

要更新,就把新版解壓縮到原本的資料夾,蓋掉舊的,再到同一個頁面重新載入擴充功能。

## 連上你的機器

打開擴充功能的設定,輸入機器的位址,按「儲存並連線」。瀏覽器會問你要不要讓擴充功能連到這個位址,其他網站它不會要。純 `http` 也可以,給區網或 Tailscale 上的機器用。

不登入也可以。沒有帳號時會匿名上傳,前提是這台機器開放匿名上傳。

「登入」會在新分頁打開機器自己的登入頁,所以密碼、驗證 App 的碼、通行密鑰和外部帳號都能用。登入之後,擴充功能會在那裡建立一個 API 權杖,然後關掉分頁。權杖的名稱是「瀏覽器擴充」加上瀏覽器和日期。它可以上傳、列出和刪掉你的分享,而且不會超過你帳號本身能做的事。你的帳號要有管理 API 權杖的權限才能這樣登入。沒有的話,請管理員開,或改用貼上權杖的方式。

「改用 API 金鑰」是貼上你在網站上建立的權杖。擴充功能會先向機器確認它有效,才存下來。

登出時,如果瀏覽器在網站上還是登入狀態,擴充功能會撤銷它自己建立的權杖。否則權杖會繼續有效,擴充功能會提醒你到網站的「API 金鑰」頁面撤銷。貼上的權杖一律不會自動撤銷。

## 右鍵選單

按右鍵,選「上傳到 Tessera」。會出現哪些選項,要看你按在什麼上面。

| 按在 | 選項 |
| --- | --- |
| 圖片、影片或音訊 | 上傳那個檔案 |
| 連結 | 上傳連結指向的檔案,或分享連結本身 |
| 選取的文字 | 上傳成筆記 |
| 頁面 | 分享這個頁面的網址 |

分享連結或網址會建立一份[連結分享](/zh-TW/docs/shares#送出東西),打開它的人會被送到那個位址。

上傳完成時,連結已經在剪貼簿裡,也會跳出通知。按通知可以打開那份分享。

選取的程式碼會保留它的語言,分享頁才能上色。擴充功能先從程式碼區塊讀語言,再從網址裡的檔名判斷,最後才用猜的。一般的文字不會被當成程式碼。

### 抓不到檔案時

擴充功能會先自己抓檔案,並帶上你的 cookie,所以要登入才看得到的圖片也抓得到。如果檔案所在的伺服器拒絕,就改由顯示它的那個頁面去抓,上限是 64 MiB。這種網站上更大的檔案,要在設定裡開啟「從任何網站擷取媒體」,這會向瀏覽器要求存取所有網站的權限。

串流播放的影片沒有完整的檔案可以抓,所以無法上傳。

## 上傳預設值

右鍵上傳的東西,以及在彈出視窗裡打的筆記,都照設定裡的這幾項:

- **端對端加密**:一開始是關的,而且只有機器提供這個功能時才會出現。檔案在瀏覽器裡就封好,金鑰放在連結的 `#` 後面。見[端對端加密](/zh-TW/docs/encryption)。連結分享一律不加密,因為伺服器得讀到網址才能把人送過去。
- **保存期限**:分享能活多久。沒選的話用機器的預設值,而且不會超過機器的上限。
- **下載即焚**:一開始是關的。分享在第一次取件後就失效。
- 上傳完成時複製連結,以及上傳完成或失敗時跳通知。這兩項一開始都是開的。

如果機器不接受其中某一項,這份分享會被刪掉,不會留下一份設定和你要的不一樣的分享。在網站上上傳時用的是網站自己的選項,不是這裡的。

## 彈出視窗

按擴充功能的圖示,可以看到正在上傳的東西(可以取消)和你自己的分享(可以刪掉)。裡面也有一個框,可以直接上傳一小段筆記。「上傳檔案」會打開網站的上傳頁,從磁碟選檔案要在那裡做。另外還有按鈕可以開網站,帳號能用管理後台的話也能直接開後台。

<Callout type="warn" title="加密分享的連結,只有上傳它的瀏覽器給得出來">
  金鑰從來不會送到機器上。換一個瀏覽器還是看得到這份分享,但組不出完整的連結。
</Callout>
