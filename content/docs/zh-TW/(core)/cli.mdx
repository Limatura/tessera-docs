`tess` 是指令列的用戶端。它可以上傳檔案、資料夾或一段筆記並印出連結,也可以下載分享。它還能列出和刪掉你自己的分享,上傳被打斷時也能接著傳。只打 `tess` 不加參數,會打開一個[全螢幕介面](#全螢幕介面),用來挑檔案和管理分享。

## 安裝

Linux 和 macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/Limatura/tessera/main/scripts/install.sh | sh
```

腳本會從最新的發布版下載適合你機器的版本,用發布版附的 `SHA256SUMS` 核對過,再把 `tess` 放進 `~/.local/bin`。那個目錄不在 `PATH` 裡的話,它會告訴你要加哪一行。

```bash
curl -fsSL https://raw.githubusercontent.com/Limatura/tessera/main/scripts/install.sh | sh -s -- --version 0.1.0 --dir /usr/local/bin
```

`--version` 會改裝指定的版本,而不是最新的正式版,預發布版也可以。`--dir` 指定放哪。`TESS_VERSION` 和 `TESS_INSTALL_DIR` 效果一樣。要更新就再跑一次。

有 Linux(x86_64 和 arm64,靜態連結,哪個發行版都能跑)和 macOS(Intel 和 Apple Silicon)的版本。Windows 請到[發布頁](https://github.com/Limatura/tessera/releases)下載 `tess-windows-x86_64.zip`。

要自己編的話,需要 Rust 1.97 以上:

```bash
cargo install --locked --git https://github.com/Limatura/tessera tessera-cli
```

## 登入

不登入也可以。沒有帳號時,只要這台機器開放匿名上傳,`tess send` 就會匿名上傳;`tess get` 則從來不需要帳號。登入之後會記住是哪台機器,就不用每次都給 `--server`,上傳也會算在你的帳號下,而且可以用 `tess ls` 和 `tess rm`。

```bash
tess login https://files.example.com
```

它會顯示一個連結、一組短碼,以及連結的 QR code。在任何已經登入的瀏覽器打開連結,確認頁面上的碼一樣,再按允許。用別台機器也可以,也能用手機掃 QR code 核准,透過 SSH 連線、沒有瀏覽器可開的時候就很方便。這個請求 10 分鐘內有效。

位址沒寫 `https://` 的話,例如 `files.example.com`,就當作 HTTPS。`--server` 也一樣。

另外兩種方式:

- `tess login --password https://files.example.com` 會問你的使用者名稱或 email 和密碼,有開[兩步驟驗證](/zh-TW/docs/accounts#兩步驟驗證)的話還會問驗證 App 上的碼。只用通行密鑰或外部帳號登入的帳號沒有密碼,請用瀏覽器。
- `tess login --with-token https://files.example.com` 從標準輸入讀一個 API 權杖,給腳本和 CI 用。權杖在帳號頁產生。

瀏覽器和密碼這兩種方式會建立一個 API 權杖,名稱是「tessera CLI on」加上機器名稱。它可以建立、列出和刪掉你的分享,而且不會超過你帳號本身能做的事。要讓那台機器登出,就到帳號頁撤銷它。

機器位址和權杖存在 `~/.config/tessera/config.toml`,只有你讀得到。Windows 上是在漫遊的 AppData 底下。存下來的權杖只會送給發它的那台機器:`--server` 指到別台時,不會帶權杖。

## 送出

```bash
tess send report.pdf
tess send photos/ notes.txt
echo "wifi 密碼貼在冰箱上" | tess send -
```

同一個指令列出的東西會變成同一份分享。資料夾會送出底下所有檔案,保留它們的路徑。資料夾裡的空檔案會被略過,因為分享不能裝空檔案,除非有加密。`-` 從標準輸入讀一段筆記;筆記自己就是一份分享,不能和檔案混在一起送。

連結印在標準輸出上,而且標準輸出只有連結,所以 `link=$(tess send report.pdf)` 可以直接用。進度和訊息走標準錯誤,進度只在終端機上才會出現。

| 選項 | 作用 |
| --- | --- |
| `--expires <HOURS>` | 分享能活幾小時 |
| `--max-uses <N>` | 能取件幾次 |
| `--password` | 問兩次密碼,或讀 `TESSERA_PASSWORD` |
| `--encrypt` | 在這台電腦上封好再送,這台機器要有開端對端加密。見[端對端加密](/zh-TW/docs/encryption) |
| `--qr` | 另外把連結畫成 QR code,給手機掃 |
| `--copy` | 另外把連結放進剪貼簿 |
| `--server <URL>` | 哪台機器。預設是 `tess login` 存下的那台,或 `TESSERA_SERVER` |
| `--token <TOKEN>` | API 權杖。預設是存下來的那個,或 `TESSERA_TOKEN` |

密碼從來不從指令參數拿,因為 `ps` 和 shell 的歷史紀錄看得到。沒加 `--encrypt` 時,它是一般的分享密碼。加了 `--encrypt`,金鑰就從密碼算出來,所以至少要 12 個字元。

`--copy` 有桌面剪貼簿時就用它。透過 SSH 時改請你的終端機複製,終端機允許的話就會成功。

### 上傳被打斷時

再跑一次同一個指令。送的過程中,`tess` 會在 `~/.local/state/tessera/uploads/` 記下送到哪裡,同樣的檔案送到同一台機器就會從那裡接著傳。

如果檔案改過了,或伺服器已經丟掉沒傳完的上傳(`upload_session_ttl_hours` 之後,預設 24 小時),就會從頭開始。加密的上傳要用同一個密碼才能接著傳。

<Callout type="warn" title="被打斷的加密上傳會把金鑰留在磁碟上">
  已經上傳的部分是用那把金鑰封的,剩下的也得用它。那個檔案只有你讀得到,送完就會刪掉。如果你不打算再送了,請自己刪掉它。
</Callout>

## 下載

```bash
tess get https://files.example.com/s/0ZPQ4M7K
tess get 0ZPQ4M7K -o downloads/
```

`tess` 知道是哪台機器時(從 `--server` 或 `tess login`),只給取件碼也可以。檔案寫到目前的目錄,或 `-o` 指定的目錄,並印出路徑。筆記則印在標準輸出。

下載會用掉一次取件次數,不管裡面有幾個檔案。分享有密碼的話,`tess` 會問你,或讀 `TESSERA_PASSWORD`。加密的連結靠 `#` 後面的金鑰打開,所以要貼整條連結。如果這台機器還在掃毒,`tess` 最多會等五分鐘。

`tess get` 不會覆蓋已經存在的檔案。它也只保留每個檔名裡一般的路徑段,所以像 `../../.bashrc` 這種名字會落在你選的目錄裡,變成 `.bashrc`。

## 你自己的分享

這兩個要先登入。

```bash
tess ls
tess rm 0ZPQ4M7K
```

`tess ls` 由新到舊列出你的分享,包括取件碼、剩多久、剩幾次和名稱。連結分享的名稱顯示為 `(link)`。`tess rm` 用取件碼或連結刪掉一份。

## 全螢幕介面

在終端機裡只打 `tess`,它會用全螢幕打開目前的資料夾,讓你不打路徑就能挑檔案、送出,並管理你的分享。如果輸入或輸出不是終端機,`tess` 會改成印出說明。

介面用的是 `tess login` 存下的機器和權杖,不讀 `--server` 和 `TESSERA_` 開頭的環境變數。還沒存過機器時會從歡迎畫面開始,可以在那裡登入。瀏覽和尋找檔案不需要帳號。

### 檔案和分享

**Files** 分頁列出資料夾的內容。用 Space 標記檔案,可以跨好幾個資料夾,再按 Ctrl-S 送出。沒有標記任何東西時,Ctrl-S 送的是游標所在的檔案。直接打字會篩選清單。Ctrl-F 會在資料夾底下用路徑裡的幾個字找檔案,`.gitignore` 排除的會略過。

**Shares** 分頁列出你自己的分享,期限以這台電腦的時間顯示成日期和時刻。按 Enter 可以看一份分享的完整資訊,包括連結和 QR code。複製加密分享的連結時不會帶金鑰,介面會提醒你。

貼上分享連結,會把它下載到目前的資料夾。Ctrl-N 可以寫一段筆記,或建立連結分享。

| 要做的事 | 按鍵 | vim 按鍵 |
| --- | --- | --- |
| 移動 | ↑ ↓、PgUp PgDn、Home End | j k、Ctrl-F Ctrl-B、g G |
| 進入資料夾、回上一層 | → 或 Enter、← 或 Backspace | l、h |
| 在去過的資料夾間後退、前進 | Alt-← Alt-→ | H L |
| 標記一個、全部標記 | Space、Ctrl-A | Space、a |
| 篩選、尋找、跳到路徑 | 直接打字、Ctrl-F、Ctrl-L | /、f、: |
| 送出 | Ctrl-S | s |
| 寫筆記或建立連結分享 | Ctrl-N | n |
| 從連結下載 | Ctrl-G | p |
| 複製分享的連結、刪掉分享 | Ctrl-Y、Del | y、d |
| 設定、傳輸、排序 | F3、F4、F6 | F3、F4、o |
| 切換分頁 | Tab | Tab |
| 看所有按鍵 | F1 | ? |
| 離開 | Ctrl-Q | q |

也可以用滑鼠。點一列選它,點它的方框標記它,雙擊打開資料夾或送出檔案,按右鍵叫出選單。拖曳選取文字,放開時就會複製。沒有桌面剪貼簿時改經由終端機複製,所以終端機允許的話,SSH 連線上也能用。F2 可以在這次使用中關掉滑鼠,選取就交還給終端機自己處理。

### 送出

送出表單的選項和 `tess send` 一樣:加密、密碼、分享能活多久、能下載幾次。表單會配合機器:機器沒提供加密就不顯示加密,超過上限的期限也不列出,上傳需要帳號時會請你先登入。在任何欄位按 Ctrl-S 都會送出。

送出和下載都在背景進行,可以同時好幾個。每一個都會有對話框顯示進度,按 **Hide** 可以關掉對話框、讓它繼續跑。F4 會列出所有進行中的傳輸,可以個別停止。送完時會顯示連結和 QR code。停掉之後再送一次同樣的檔案,會從停下的地方接著傳。

能顯示圖片的終端機,例如 kitty、Ghostty、WezTerm、iTerm2、Windows Terminal 和 foot,會把 QR code 畫成圖片,其他終端機則用半格方塊畫,tmux 和 screen 裡也是。VS Code 的終端機要開啟 `terminal.integrated.enableImages` 才會顯示圖片。

### 設定

F3 可以改按鍵、滑鼠、要不要顯示點開頭的檔案、排序和顏色。每改一項,就立刻存進設定檔的 `[ui]` 表格。

```toml
[ui]
keys = "vim"        # or "standard"
mouse = true
show_hidden = false
sort = "modified"   # "name", "modified" or "size"
accent = "teal"     # violet, rose, orange, amber, green, teal or blue

[ui.bindings]
send = "ctrl-s"
up = ["k", "up"]
```

`[ui.bindings]` 用來改個別動作的按鍵,各動作的名稱可以在 F1 看到。這裡指定的按鍵,會從原本使用它的動作上拿掉。`[ui]` 裡有 `tess` 不認得的動作、按鍵或項目時,`tess` 會在啟動時報錯停下。

沒設 `accent` 的話,介面會用你在網站上選的顏色,再來是機器自己的顏色。

## Shell 自動補全

`tess completions <shell>` 會印出補全腳本。支援 `bash`、`zsh`、`fish`、`elvish` 和 `powershell`。

```bash
tess completions zsh > ~/.zfunc/_tess
tess completions bash > ~/.local/share/bash-completion/completions/tess
```
