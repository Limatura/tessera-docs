扩展会把你右键点到的东西上传到你的机器,并复制链接。它可以在 Chrome、Edge、Brave 等 Chromium 浏览器上用,Firefox 要 128 以上。

## 安装

它没有上架浏览器的商店。请到[发布页](https://github.com/Limatura/tessera/releases)下载并解压:Chromium 浏览器用 `tessera-extension-chrome.zip`,Firefox 用 `tessera-extension-firefox.zip`。

- **Chromium 浏览器**:打开 `chrome://extensions`,开启开发者模式,选「加载已解压的扩展程序」,再选解压出来的文件夹。
- **Firefox**:打开 `about:debugging#/runtime/this-firefox`,选「临时载入附加组件」,再选解压文件夹里的 `manifest.json`。这个版本没有经过 Mozilla 签名,所以 Firefox 重启后就会移除它。

要更新,就把新版解压到原来的文件夹,覆盖旧的,再到同一个页面重新加载扩展。

## 连上你的机器

打开扩展的设置,输入机器的地址,点「保存并连接」。浏览器会问你要不要让扩展连到这个地址,其他网站它不会要。纯 `http` 也可以,给局域网或 Tailscale 上的机器用。

不登录也可以。没有账号时会匿名上传,前提是这台机器开放匿名上传。

「登录」会在新标签页打开机器自己的登录页,所以密码、验证 App 的码、通行密钥和外部账号都能用。登录之后,扩展会在那里创建一个 API 令牌,然后关掉标签页。令牌的名称是「浏览器扩展」加上浏览器和日期。它可以上传、列出和删除你的分享,而且不会超过你账号本身能做的事。你的账号要有管理 API 令牌的权限才能这样登录。没有的话,请管理员开,或改用粘贴令牌的方式。

「改用 API 密钥」是粘贴你在网站上创建的令牌。扩展会先向机器确认它有效,才存下来。

退出登录时,如果浏览器在网站上还是登录状态,扩展会撤销它自己创建的令牌。否则令牌会继续有效,扩展会提醒你到网站的「API 密钥」页面撤销。粘贴的令牌一律不会自动撤销。

## 右键菜单

点右键,选「上传到 Tessera」。会出现哪些选项,要看你点在什么上面。

| 点在 | 选项 |
| --- | --- |
| 图片、视频或音频 | 上传那个文件 |
| 链接 | 上传链接指向的文件,或分享链接本身 |
| 选中的文字 | 上传成笔记 |
| 页面 | 分享这个页面的网址 |

分享链接或网址会创建一份[链接分享](/zh-CN/docs/shares#发送东西),打开它的人会被送到那个地址。

上传完成时,链接已经在剪贴板里,也会弹出通知。点通知可以打开那份分享。

选中的代码会保留它的语言,分享页才能上色。扩展先从代码块读语言,再从网址里的文件名判断,最后才靠猜。普通的文字不会被当成代码。

### 抓不到文件时

扩展会先自己抓文件,并带上你的 cookie,所以要登录才看得到的图片也抓得到。如果文件所在的服务器拒绝,就改由显示它的那个页面去抓,上限是 64 MiB。这种网站上更大的文件,要在设置里开启「从任意网站获取媒体」,这会向浏览器申请访问所有网站的权限。

流式播放的视频没有完整的文件可以抓,所以无法上传。

## 上传默认值

右键上传的东西,以及在弹出窗口里输入的笔记,都按设置里的这几项来:

- **端到端加密**:一开始是关的,而且只有机器提供这个功能时才会出现。文件在浏览器里就封好,密钥放在链接的 `#` 后面。见[端对端加密](/zh-CN/docs/encryption)。链接分享一律不加密,因为服务器得读到网址才能把人送过去。
- **保存期限**:分享能活多久。没选的话用机器的默认值,而且不会超过机器的上限。
- **下载即焚**:一开始是关的。分享在第一次取件后就失效。
- 上传完成时复制链接,以及上传完成或失败时弹通知。这两项一开始都是开的。

如果机器不接受其中某一项,这份分享会被删掉,不会留下一份设置和你要的不一样的分享。在网站上上传时用的是网站自己的选项,不是这里的。

## 弹出窗口

点扩展的图标,可以看到正在上传的东西(可以取消)和你自己的分享(可以删除)。里面也有一个框,可以直接上传一小段笔记。「上传文件」会打开网站的上传页,从磁盘选文件要在那里做。另外还有按钮可以打开网站,账号能用管理后台的话也能直接打开后台。

<Callout type="warn" title="加密分享的链接,只有上传它的浏览器给得出来">
  密钥从来不会发到机器上。换一个浏览器还是看得到这份分享,但拼不出完整的链接。
</Callout>
