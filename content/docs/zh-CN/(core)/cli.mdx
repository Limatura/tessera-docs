`tess` 是命令行客户端。它可以上传文件、文件夹或一段笔记并打印链接,也可以下载分享。它还能列出和删除你自己的分享,上传被打断时也能接着传。只输入 `tess` 不加参数,会打开一个[全屏界面](#全屏界面),用来挑文件和管理分享。

## 安装

Linux 和 macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/Limatura/tessera/main/scripts/install.sh | sh
```

脚本会从最新的发布版下载适合你机器的版本,用发布版附带的 `SHA256SUMS` 校验过,再把 `tess` 放进 `~/.local/bin`。那个目录不在 `PATH` 里的话,它会告诉你要加哪一行。

```bash
curl -fsSL https://raw.githubusercontent.com/Limatura/tessera/main/scripts/install.sh | sh -s -- --version 0.1.0 --dir /usr/local/bin
```

`--version` 会改装指定的版本,而不是最新的正式版,预发布版也可以。`--dir` 指定放哪。`TESS_VERSION` 和 `TESS_INSTALL_DIR` 效果一样。要更新就再跑一次。

有 Linux(x86_64 和 arm64,静态链接,哪个发行版都能跑)和 macOS(Intel 和 Apple Silicon)的版本。Windows 请到[发布页](https://github.com/Limatura/tessera/releases)下载 `tess-windows-x86_64.zip`。

要自己编译的话,需要 Rust 1.97 以上:

```bash
cargo install --locked --git https://github.com/Limatura/tessera tessera-cli
```

## 登录

不登录也可以。没有账号时,只要这台机器开放匿名上传,`tess send` 就会匿名上传;`tess get` 则从来不需要账号。登录之后会记住是哪台机器,就不用每次都给 `--server`,上传也会算在你的账号下,而且可以用 `tess ls` 和 `tess rm`。

```bash
tess login https://files.example.com
```

它会显示一个链接、一组短码,以及链接的二维码。在任何已经登录的浏览器打开链接,确认页面上的码一样,再点允许。用别的机器也可以,也能用手机扫二维码批准,通过 SSH 连接、没有浏览器可开的时候就很方便。这个请求 10 分钟内有效。

地址没写 `https://` 的话,例如 `files.example.com`,就当作 HTTPS。`--server` 也一样。

另外两种方式:

- `tess login --password https://files.example.com` 会问你的用户名或邮箱和密码,开了[两步验证](/zh-CN/docs/accounts#两步验证)的话还会问验证 App 上的码。只用通行密钥或外部账号登录的账号没有密码,请用浏览器。
- `tess login --with-token https://files.example.com` 从标准输入读一个 API 令牌,给脚本和 CI 用。令牌在账号页生成。

浏览器和密码这两种方式会创建一个 API 令牌,名称是「tessera CLI on」加上机器名。它可以创建、列出和删除你的分享,而且不会超过你账号本身能做的事。要让那台机器退出登录,就到账号页撤销它。

机器地址和令牌存在 `~/.config/tessera/config.toml`,只有你读得到。Windows 上是在漫游的 AppData 下面。存下来的令牌只会发给签发它的那台机器:`--server` 指到别的机器时,不会带令牌。

## 发送

```bash
tess send report.pdf
tess send photos/ notes.txt
echo "wifi 密码贴在冰箱上" | tess send -
```

同一个命令列出的东西会变成同一份分享。文件夹会发送里面的所有文件,保留它们的路径。文件夹里的空文件会被跳过,因为分享不能装空文件,除非加了密。`-` 从标准输入读一段笔记;笔记自己就是一份分享,不能和文件混在一起发。

链接打印在标准输出上,而且标准输出只有链接,所以 `link=$(tess send report.pdf)` 可以直接用。进度和消息走标准错误,进度只在终端里才会出现。

| 选项 | 作用 |
| --- | --- |
| `--expires <HOURS>` | 分享能活几小时 |
| `--max-uses <N>` | 能取件几次 |
| `--password` | 问两次密码,或读 `TESSERA_PASSWORD` |
| `--encrypt` | 在这台电脑上封好再发,这台机器要开了端对端加密。见[端对端加密](/zh-CN/docs/encryption) |
| `--qr` | 另外把链接画成二维码,给手机扫 |
| `--copy` | 另外把链接放进剪贴板 |
| `--server <URL>` | 哪台机器。默认是 `tess login` 存下的那台,或 `TESSERA_SERVER` |
| `--token <TOKEN>` | API 令牌。默认是存下来的那个,或 `TESSERA_TOKEN` |

密码从来不从命令参数拿,因为 `ps` 和 shell 的历史记录看得到。没加 `--encrypt` 时,它是普通的分享密码。加了 `--encrypt`,密钥就从密码算出来,所以至少要 12 个字符。

`--copy` 有桌面剪贴板时就用它。通过 SSH 时改让你的终端复制,终端允许的话就会成功。

### 上传被打断时

再跑一次同一个命令。发送过程中,`tess` 会在 `~/.local/state/tessera/uploads/` 记下传到哪里,同样的文件发到同一台机器就会从那里接着传。

如果文件改过了,或服务器已经丢掉没传完的上传(`upload_session_ttl_hours` 之后,默认 24 小时),就会从头开始。加密的上传要用同一个密码才能接着传。

<Callout type="warn" title="被打断的加密上传会把密钥留在磁盘上">
  已经上传的部分是用那把密钥封的,剩下的也得用它。那个文件只有你读得到,发完就会删掉。如果你不打算再发了,请自己删掉它。
</Callout>

## 下载

```bash
tess get https://files.example.com/s/0ZPQ4M7K
tess get 0ZPQ4M7K -o downloads/
```

`tess` 知道是哪台机器时(从 `--server` 或 `tess login`),只给取件码也可以。文件写到当前目录,或 `-o` 指定的目录,并打印路径。笔记则打印在标准输出。

下载会用掉一次取件次数,不管里面有几个文件。分享有密码的话,`tess` 会问你,或读 `TESSERA_PASSWORD`。加密的链接靠 `#` 后面的密钥打开,所以要贴整条链接。如果这台机器还在扫毒,`tess` 最多会等五分钟。

`tess get` 不会覆盖已经存在的文件。它也只保留每个文件名里普通的路径段,所以像 `../../.bashrc` 这种名字会落在你选的目录里,变成 `.bashrc`。

## 你自己的分享

这两个要先登录。

```bash
tess ls
tess rm 0ZPQ4M7K
```

`tess ls` 从新到旧列出你的分享,包括取件码、剩多久、剩几次和名称。链接分享的名称显示为 `(link)`。`tess rm` 用取件码或链接删掉一份。

## 全屏界面

在终端里只输入 `tess`,它会用全屏打开当前文件夹,让你不输入路径就能挑文件、发送,并管理你的分享。如果输入或输出不是终端,`tess` 会改为打印帮助。

界面用的是 `tess login` 存下的机器和令牌,不读 `--server` 和 `TESSERA_` 开头的环境变量。还没存过机器时会从欢迎画面开始,可以在那里登录。浏览和查找文件不需要账号。

### 文件和分享

**Files** 标签页列出文件夹的内容。用 Space 标记文件,可以跨好几个文件夹,再按 Ctrl-S 发送。没有标记任何东西时,Ctrl-S 发送的是光标所在的文件。直接打字会筛选列表。Ctrl-F 会在文件夹下面用路径里的几个字找文件,`.gitignore` 排除的会跳过。

**Shares** 标签页列出你自己的分享,期限以这台电脑的时间显示为日期和时刻。按 Enter 可以看一份分享的完整信息,包括链接和二维码。复制加密分享的链接时不会带密钥,界面会提醒你。

粘贴分享链接,会把它下载到当前文件夹。Ctrl-N 可以写一段笔记,或创建链接分享。

| 要做的事 | 按键 | vim 按键 |
| --- | --- | --- |
| 移动 | ↑ ↓、PgUp PgDn、Home End | j k、Ctrl-F Ctrl-B、g G |
| 进入文件夹、回上一层 | → 或 Enter、← 或 Backspace | l、h |
| 在去过的文件夹间后退、前进 | Alt-← Alt-→ | H L |
| 标记一个、全部标记 | Space、Ctrl-A | Space、a |
| 筛选、查找、跳到路径 | 直接打字、Ctrl-F、Ctrl-L | /、f、: |
| 发送 | Ctrl-S | s |
| 写笔记或创建链接分享 | Ctrl-N | n |
| 从链接下载 | Ctrl-G | p |
| 复制分享的链接、删除分享 | Ctrl-Y、Del | y、d |
| 设置、传输、排序 | F3、F4、F6 | F3、F4、o |
| 切换标签页 | Tab | Tab |
| 看所有按键 | F1 | ? |
| 退出 | Ctrl-Q | q |

也可以用鼠标。点一行选中它,点它的方框标记它,双击打开文件夹或发送文件,点右键调出菜单。拖动选中文字,松开时就会复制。没有桌面剪贴板时改经由终端复制,所以终端允许的话,SSH 连接上也能用。F2 可以在这次使用中关掉鼠标,选中就交还给终端自己处理。

### 发送

发送表单的选项和 `tess send` 一样:加密、密码、分享能活多久、能下载几次。表单会配合机器:机器没提供加密就不显示加密,超过上限的期限也不列出,上传需要账号时会请你先登录。在任何字段按 Ctrl-S 都会发送。

发送和下载都在后台进行,可以同时好几个。每一个都会有对话框显示进度,按 **Hide** 可以关掉对话框、让它继续跑。F4 会列出所有进行中的传输,可以单独停止。发完时会显示链接和二维码。停掉之后再发一次同样的文件,会从停下的地方接着传。

能显示图片的终端,例如 kitty、Ghostty、WezTerm、iTerm2、Windows Terminal 和 foot,会把二维码画成图片,其他终端则用半格方块画,tmux 和 screen 里也是。VS Code 的终端要开启 `terminal.integrated.enableImages` 才会显示图片。

### 设置

F3 可以改按键、鼠标、要不要显示点开头的文件、排序和颜色。每改一项,就立刻存进配置文件的 `[ui]` 表。

```toml
[ui]
keys = "vim"        # or "standard"
mouse = true
show_hidden = false
sort = "modified"   # "name", "modified" or "size"
accent = "teal"     # violet, rose, orange, amber, green, teal or blue

[ui.bindings]
send = "ctrl-s"
up = ["k", "up"]
```

`[ui.bindings]` 用来改单个动作的按键,各动作的名称可以在 F1 看到。这里指定的按键,会从原来使用它的动作上拿掉。`[ui]` 里有 `tess` 不认识的动作、按键或项目时,`tess` 会在启动时报错停下。

没设 `accent` 的话,界面会用你在网站上选的颜色,再来是机器自己的颜色。

## Shell 自动补全

`tess completions <shell>` 会打印补全脚本。支持 `bash`、`zsh`、`fish`、`elvish` 和 `powershell`。

```bash
tess completions zsh > ~/.zfunc/_tess
tess completions bash > ~/.local/share/bash-completion/completions/tess
```
